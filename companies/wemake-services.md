# wemake.services

wemake.services publishes a software-services working model focused on open-source contributions, code review and project-oriented delivery.

- **Category:** Software consulting
- **Website:** [Website](https://wemake.services/)
- **Jobs / careers:** [Careers](https://wemake.services/meta/rsdp/job-application)
- **Historical remote signal:** Spain remote signal

The official recruiting handbook is continuously open to developers, says work is only remote, and explicitly says where a person is based does not matter. This worldwide recruiting policy supports Spain company-watch eligibility. Work is paid per task with an agreed hourly rate used for estimates, compatible with another full-time job; it is not a salaried-employee offering.

- **Historical record reviewed:** 2026-11-11
- **Public-source research date:** 2026-11-11

## Verification caveat

Eligibility is role- and country-specific. Policy, talent-pool and empty-board evidence is not a guarantee of a current vacancy or of unrestricted cross-border employment. The original upstream interview-process claim has not been independently certified.
