# Dropbox

Dropbox provides cloud file storage, synchronization, sharing and collaboration tools, including electronic signatures and AI-powered content discovery.

- **Category:** Cloud collaboration software
- **Website:** [Website](https://www.dropbox.com/)
- **Jobs / careers:** [Careers](https://www.dropbox.jobs/en/jobs/)
- **Historical remote signal:** Hybrid or country-restricted evidence

Dropbox describes a Virtual First model with remote day-to-day work, core collaboration hours and intentional in-person gatherings. Official listings checked on 4 November 2026 include remote roles in Poland, Ireland and the United Kingdom. Hiring is limited to authorized locations for each vacancy, not all European countries.

## Verification caveat
