# OneSignal

OneSignal develops tools for push notifications, email, messaging and customer engagement automation.

- **Category:** Customer engagement software
- **Website:** [Website](https://onesignal.com/)
- **Jobs / careers:** [Careers](https://onesignal.com/careers)
- **Historical remote signal:** Hybrid or country-restricted evidence

OneSignal’s official Gem Renewals Manager advert is United Kingdom (Remote), full-time, and expressly supports UK remote work as the default. It covers EMEA/APAC renewals and asks about UK work authorization and sponsorship. This establishes UK, not EU-wide remote hiring. Another SRE/Platform page displays Spain (Remote) alongside UK but asks specifically for UK work rights; Spain employment remains unconfirmed rather than resolving that conflict optimistically.
